# فَحْص | FAHS SECURITY

![FAHS Security](assets/fahs-logo.svg)
**لا تثق... تحقّق.**

بوت تيليجرام عربي للتوعية بالأمن الرقمي وفحص مؤشرات خطورة الروابط.

## النطاق
- فحص الروابط النصية، بما فيها المختصرة وروابط التحويل.
- تحليل صياغة الرابط والنطاق وDNS ومؤشرات التصيد، بما فيها بعض أنماط تشابه النطاقات مع العلامات المعروفة.
- مقارنة الروابط بمصادر تهديد عامة عند تفعيلها.
- موسوعة توعوية، نصائح، اختبارات، وإرشادات الطوارئ.
- وضع حماية للمجموعات عند تفعيل صلاحيات البوت وإعدادات الخصوصية المناسبة.
- رسائل تذكير اختيارية فقط بعد اشتراك المستخدم.

**لا يفحص فَحْص الصور أو الملفات أو محتويات التنزيلات.** لا يفتح روابط المستخدم تلقائيًا في المتصفح، ولا يطلب كلمات مرور أو رموز تحقق.

## تشغيل محلي
1. استخدم Python 3.11 أو أحدث.
2. أنشئ بوتًا عبر BotFather وخذ الرمز.
3. انسخ `.env.example` إلى `.env` وأضف `BOT_TOKEN`.
4. ثبّت الاعتماديات: `pip install -r requirements.txt`.
5. شغّل: `python -m fahs`.

## إعدادات مهمة
- `ADMIN_IDS`: معرّفات مشرفي البوت، مفصولة بفواصل.
- `DATABASE_PATH`: مسار قاعدة SQLite.
- `MAX_REDIRECTS`, `REQUEST_TIMEOUT`: حدود الفحص.
- `OPENPHISH_FEED_URL`: اختياري؛ يقبل نطاق OpenPhish الرسمي فقط ولا تُرسل إليه روابط المستخدم.
- `URLHAUS_AUTH_KEY`: اختياري؛ مفتاح URLhaus المجتمعي، ويُستخدم لتنزيل أحدث 1000 مؤشر محليًا دون إرسال الرابط الذي تفحصه. تُخزّن المفاتيح في متغيرات البيئة فقط.
- `UPDATES_URL`, `DEVELOPER_URL`, `SUPPORT_URL`: روابط الأزرار، ويمكن تركها فارغة.

## الخصوصية والأمان
- لا تُخزَّن الروابط المفحوصة افتراضيًا.
- تُحفظ إعدادات الاشتراك الضرورية ومعرّفات تيليجرام لتقديم الخدمة.
- لا تُرسل الروابط ذات بيانات الاعتماد أو الرموز السرية إلى أي مصدر خارجي.
- فاحص التحويلات يستخدم طلبات HEAD فقط، ويتصل بعنوان IP عام تم التحقق منه مع الحفاظ على اسم النطاق للتحقق من TLS؛ ويعيد تطبيق التحقق عند كل تحويل.
- النتيجة «لم تظهر مؤشرات تهديد معروفة» لا تعني أن الرابط آمن 100%.

راجع `PRIVACY.md` و`SECURITY.md` و`DEPLOYMENT.md` قبل النشر العام.

## تشغيل عبر Docker
1. انسخ `.env.example` إلى `.env` وأدخل رمز البوت.
2. شغّل `docker compose up -d --build`.
3. راقب السجلات عبر `docker compose logs -f`.

## إعداد تيليجرام
- أضف البوت إلى المجموعة.
- فعّل وضع الخصوصية المناسب من BotFather إذا أردت قراءة روابط الأعضاء؛ وقد يلزم تعطيل Privacy Mode ومنح البوت صلاحية قراءة الرسائل. لا يستطيع البوت قراءة كل الرسائل افتراضيًا.
- أوامر المشرفين: `/fahs_on` و`/fahs_off` داخل المجموعة. إحصاءات المشغّل: `/admin` بعد ضبط `ADMIN_IDS`.
- الحذف التلقائي اختياري: `/fahs_delete_on` و`/fahs_delete_off`. يتطلب أن يكون البوت مشرفًا مع صلاحية حذف الرسائل. يحذف فقط الرسائل المصنفة «خطر حرج» أو «مرتفع»، وقد تحدث إيجابيات كاذبة.
- قائمة استثناءات النطاقات لكل مجموعة: `/fahs_allow example.com` و`/fahs_unallow example.com` و`/fahs_allowlist`. تُستثنى النطاقات الفرعية أيضًا، وبحد أقصى 100 نطاق. لا تضف إلا نطاقات تثق بها تمامًا؛ فالاستثناء يتجاوز الفحص لهذه الوجهات.
- روابط قناة التحديثات والمطور والدعم تُضبط عبر `UPDATES_URL` و`DEVELOPER_URL` و`SUPPORT_URL`.
- يمكن للمستخدم حذف إعداداته ومعرّفه من قاعدة البوت عبر `/delete_my_data` في المحادثة الخاصة.

## حدود النسخة الحالية
- محرك OpenPhish الاختياري يقبل رابط الخلاصة الرسمي على `openphish.com` فقط، ويحد حجم التنزيل إلى 5 MiB.
- مصدر URLhaus اختياري ويتطلب `URLHAUS_AUTH_KEY`؛ يجلب أحدث 1000 مؤشر ويخزنها مؤقتًا محليًا، ولا يرسل الرابط الذي يطلب المستخدم فحصه إلى المصدر. واجهة URLhaus المجتمعية مجانية وفق سياسة الاستخدام العادل، وقد تتطلب الاستخدامات التجارية/الربحية اشتراكًا محسّنًا. لا تغطي هذه القائمة كل تاريخ URLhaus.
- لم يُفعّل استعلام PhishTank المباشر؛ لأنه يرسل الرابط المطلوب فحصه إلى خدمة خارجية، وهو ما يتعارض مع نهج الخصوصية الحالي. يمكن إضافة تغذية محلية لاحقًا دون إرسال روابط المستخدمين.
- الحذف التلقائي للروابط عالية الخطورة موجود كخيار للمشرف، لكنه متوقف افتراضيًا.
- فحص التحويلات لا ينزّل محتوى الصفحات؛ يستخدم HEAD يدويًا مع تثبيت الاتصال على عنوان IP اجتاز التحقق، ويعيد الفحص عند كل تحويل. قد ترفض بعض المواقع HEAD، وعندها تظهر نتيجة تعذر إكمال الفحص. أضف سياسة خروج شبكي تمنع الشبكات الخاصة وعناوين metadata كطبقة دفاع إضافية.
- اختبارات CI تتحقق من الصياغة وبعض قواعد الأمان، ولا تغني عن اختبار ميداني قبل الإطلاق.
