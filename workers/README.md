# فَحْص | FAHS 🟢
بوت تيليجرام للأمن الرقمي: فحص الروابط + توعية أمنية + لوحة إدارة كاملة داخل تيليجرام.
يعمل على **Cloudflare Workers + D1** ويُنشر تلقائياً من **GitHub**.

> الكود مكتوب بـ JavaScript لأن Cloudflare Workers لا تشغّل مشاريع بايثون التقليدية (aiogram وغيرها) بشكل موثوق.

## الميزات
- 🔍 فحص الروابط: تحليل محلي (انتحال العلامات، النطاقات المموهة، IP، @، امتدادات مشبوهة…) + تتبع التحويلات للروابط المختصرة + VirusTotal.
- 🛡 أقسام توعوية جاهزة (كيف أحمي نفسي، طرق النصب، مخاطر الذكاء الاصطناعي وكلمة السر العائلية، مخاطر الروابط، 24 مصطلحاً).
- ⚙️ لوحة المالك: إضافة/حذف/إعادة تسمية/ترتيب/إخفاء الأقسام والأزرار، إضافة نص منسق وصور وفيديو وملفات وGIF وأزرار روابط، إذاعة، إحصائيات، حظر، إعدادات.
- 🔒 خصوصية: لا نخزن الروابط (النطاق فقط للإحصاء)، لا ملفات، لا كلمات مرور. حماية SSRF، تحديد معدل، سر للـ Webhook.
- ⏳ فحص الصور والملفات: غير مفعّل حالياً (الروابط فقط) حسب الطلب.

## خطوات التشغيل
1. **@BotFather** ← `/newbot` ← احفظ التوكن. (صورة البوت: `assets/logo.png` عبر `/setuserpic`)
2. اعرف رقمك (ID) من **@userinfobot**.
3. (اختياري لكن مهم) مفتاح **VirusTotal** المجاني من virustotal.com ← الملف الشخصي ← API Key.
4. ارفع محتوى هذا المجلد إلى مستودع **GitHub** (يفضل Private).
5. في Cloudflare: **Storage & Databases ← D1 ← Create** باسم `fahs-db`، وانسخ **Database ID**.
6. افتح `wrangler.jsonc` وأضف داخل عنصر D1 السطر: `"database_id": "المعرف-الذي-نسخته"` ثم احفظ (commit).
7. **Workers & Pages ← Create ← Import a repository** واختر المستودع. أمر النشر: `npx wrangler deploy`.
8. من الـ Worker ← **Settings ← Variables and Secrets** أضف كـ **Secret**:
   `BOT_TOKEN` ، `OWNER_ID` ، `WEBHOOK_SECRET` (نص عشوائي طويل من حروف وأرقام فقط) ، `VT_API_KEY`.
9. افتح في المتصفح: `https://اسم-الworker.workers.dev/setup?key=قيمة_WEBHOOK_SECRET` ← يجب أن تظهر `"webhook": true`.
10. أرسل `/start` للبوت. ستظهر لك **⚙️ لوحة الإدارة** (لأن رقمك هو OWNER_ID).

## المشاكل المتوقعة وحلولها
| المشكلة | السبب والحل |
|---|---|
| البوت لا يرد | لم تفتح رابط `/setup` أو السر غير مطابق. افتحه مجدداً. راجع Logs في Cloudflare. |
| `missing secrets` | أحد الأسرار الثلاثة غير مضاف. أضفه ثم أعد النشر. |
| فشل النشر: `database_id` | أنشئ D1 وضع المعرف في `wrangler.jsonc` (خطوة 5-6). |
| الفحص يقول «VirusTotal مشغولة» | الخطة المجانية: 4 طلبات/دقيقة و500/يوم. خفّض حد الفحص من الإعدادات أو استخدم مفتاحاً مدفوعاً. |
| الإذاعة بطيئة | تُرسل 25 مستخدماً كل دقيقة بسبب حدود الخطة المجانية. على الخطة المدفوعة ارفع `BROADCAST_BATCH` (حتى 40 في الكود، عدّل السقف عند الحاجة). |
| لا يمكن فحص رابط | قد يمنع الموقع طلب HEAD؛ يُفحص الرابط كما هو. العناوين الداخلية محجوبة عمداً. |
| ضغطت زر قديم ولم يحدث شيء | الرسالة قديمة؛ اكتب `/start`. |
| تسرب التوكن | من @BotFather: `/revoke` ثم حدّث السر وأعد فتح `/setup`. |
