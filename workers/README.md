# فَحْص | FAHS 🟢
بوت تيليجرام للأمن الرقمي: فحص الروابط + توعية أمنية + لوحة إدارة كاملة داخل تيليجرام.
يعمل على **Cloudflare Workers + D1** ويُنشر تلقائياً من **GitHub**.

> الكود مكتوب بـ JavaScript لأن Cloudflare Workers لا تشغّل مشاريع بايثون التقليدية (aiogram وغيرها) بشكل موثوق.

## الميزات
- 🔍 فحص الروابط: تحليل محلي (انتحال العلامات، النطاقات المموهة، IP، @، امتدادات مشبوهة…). لا يفتح الروابط ولا يتصل بوجهاتها؛ لذلك لا يؤكد الوجهة النهائية للمختصرات. VirusTotal متوقف افتراضياً ولا يعمل إلا عند وجود `VT_API_KEY` وتفعيل `VT_EXTERNAL_SCAN_CONSENT=1` صراحةً، إضافة إلى تفعيله من لوحة الإدارة؛ عندها تُرسل الروابط إلى طرف خارجي.
- 🛡 أقسام توعوية جاهزة (كيف أحمي نفسي، طرق النصب، مخاطر الذكاء الاصطناعي وكلمة السر العائلية، مخاطر الروابط، 24 مصطلحاً).
- ⚙️ لوحة المالك: إضافة/حذف/إعادة تسمية/ترتيب/إخفاء الأقسام والأزرار، إضافة نص منسق وصور وفيديو وملفات وGIF وأزرار روابط، إذاعة، إحصائيات، حظر، إعدادات.
- 🔒 خصوصية: لا نخزن الروابط (النطاق فقط للإحصاء)، ولا نفحص الملفات. لا توجد اتصالات إلى الروابط المقدمة، ما يقلل مخاطر SSRF. VirusTotal اختياري ومتوقف افتراضياً.
- ⏳ فحص الصور والملفات: غير مفعّل حالياً (الروابط فقط) حسب الطلب.

## خطوات التشغيل
1. **@BotFather** ← `/newbot` ← احفظ التوكن. شعار المشروع موجود في `assets/fahs-logo.svg`.
2. اعرف رقمك (ID) من **@userinfobot**.
3. (اختياري لكن مهم) مفتاح **VirusTotal** المجاني من virustotal.com ← الملف الشخصي ← API Key.
4. ارفع محتوى هذا المجلد إلى مستودع **GitHub** (يفضل Private).
5. في Cloudflare: **Storage & Databases ← D1 ← Create** باسم `fahs-db`، وانسخ **Database ID**.
6. استبدل قيمة `REPLACE_WITH_D1_DATABASE_ID` في `wrangler.jsonc` بمعرّف D1 الذي نسخته، ثم احفظ التعديل.
7. **Workers & Pages ← Create ← Import a repository** واختر المستودع واضبط Root directory على `workers`. أمر النشر: `npx wrangler deploy`.
8. من الـ Worker ← **Settings ← Variables and Secrets** أضف كـ **Secret**:
   `BOT_TOKEN` ، `OWNER_ID` ، `WEBHOOK_SECRET` (نص عشوائي طويل من حروف وأرقام فقط). لا تضف `VT_API_KEY` إلا إذا كنت ستستخدم VirusTotal، ولا تفعّل `VT_EXTERNAL_SCAN_CONSENT=1` إلا بعد موافقتك الصريحة على إرسال الروابط إلى خدمة خارجية.
9. أرسل طلب POST إلى `https://اسم-الworker.workers.dev/setup` مع ترويسة `x-fahs-setup-secret: قيمة_WEBHOOK_SECRET`. لا تضع السر في عنوان URL.
10. أرسل `/start` للبوت. ستظهر لك **⚙️ لوحة الإدارة** (لأن رقمك هو OWNER_ID).

## المشاكل المتوقعة وحلولها
| المشكلة | السبب والحل |
|---|---|
| البوت لا يرد | لم ترسل طلب POST إلى `/setup` أو السر غير مطابق. راجع Logs في Cloudflare. |
| `missing secrets` | أحد الأسرار الثلاثة غير مضاف. أضفه ثم أعد النشر. |
| فشل النشر: `database_id` | أنشئ D1 وضع المعرف في `wrangler.jsonc` (خطوة 5-6). |
| الفحص يقول «VirusTotal مشغولة» | الخطة المجانية: 4 طلبات/دقيقة و500/يوم. خفّض حد الفحص من الإعدادات أو استخدم مفتاحاً مدفوعاً. |
| الإذاعة بطيئة | تُرسل 25 مستخدماً كل دقيقة بسبب حدود الخطة المجانية. على الخطة المدفوعة ارفع `BROADCAST_BATCH` (حتى 40 في الكود، عدّل السقف عند الحاجة). |
| لا يمكن فحص رابط | قد يكون الرابط غير صالح أو يحتوي بيانات اعتماد. لا يتصل فَحْص بوجهات الروابط ولا يتتبع التحويلات.
| ضغطت زر قديم ولم يحدث شيء | الرسالة قديمة؛ اكتب `/start`. |
| تسرب التوكن | من @BotFather: `/revoke` ثم حدّث السر وأعد فتح `/setup`. |

## التطوير والاختبار
```bash
npm test          # اختبارات شاملة بقاعدة بيانات محاكاة (لا تحتاج إنترنت)
cd workers && npm install && npx wrangler dev
```
## خطط مستقبلية مقترحة
فحص الملفات عبر VirusTotal (بالهاش)، Google Safe Browsing، لغة إنجليزية، استيراد/تصدير المحتوى.


## حماية المجموعات
أضف البوت إلى المجموعة وعطّل Privacy Mode من BotFather إذا أردت قراءة روابط الرسائل العادية. يفعّل مشرف المجموعة الحماية عبر `/fahs_on` ويوقفها عبر `/fahs_off` ويستعرض حالتها عبر `/fahs_status`. الحماية متوقفة افتراضياً لكل مجموعة. لا يحذف البوت رسائل الأعضاء تلقائياً.


## حالة التنفيذ
هذا الفرع تطويري مستقل. لا توجد أسرار أو قاعدة D1 مرتبطة به بعد، ولم يُنشر Worker إلى Cloudflare. لا تضع مفاتيحك في GitHub؛ أضفها في Cloudflare Secrets فقط.
